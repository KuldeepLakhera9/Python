# 07. Database Integration & SQL in Python

Connecting Python pipelines with relational & non-relational databases:
- **SQLite**: Built-in lightweight SQL engine (`sqlite3`).
- **PostgreSQL / MySQL**: `psycopg2`, `pymysql` database connectors.
- **SQLAlchemy / ORM**: Database abstractions, pooled connections, SQL query execution.
- **Bulk Loading**: Fast inserts (`to_sql`, `COPY FROM`).
