# 05. File Handling & Data Formats

Working with structured, semi-structured, and columnar file formats in Python:
- **CSV & TSV**: Native `csv` module & delimiter handling.
- **JSON & JSONL**: Nested data parsing, payload flattening.
- **Parquet & Avro**: Columnar storage, compression, PyArrow usage.
- **File I/O**: Context managers (`with open(...)`), streaming chunks.
